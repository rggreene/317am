# Game assets

v0.4 currently contains procedural art embedded in `index.html`. This directory reserves space for forthcoming external assets:

- `models/` — exported optimized `.glb` meshes
- `source/` — Blender project files and editable art
- `textures/` — external textures where needed
- `audio/` — sound effects and ambience

See [the asset pipeline](../docs/ASSET_PIPELINE.md) before importing authored models.
